# CodSoft Python Programming Internship

This repository contains the tasks completed as part of the **Python Programming Internship** at **CodSoft**.

---

## 📌 Tasks Included

### 1. Task 2: Calculator
* **File:** `task2_calculator.py`
* **Description:** A simple command-line calculator that performs basic arithmetic operations (Addition, Subtraction, Multiplication, Division) based on user input.

### 2. Task 3: Password Generator
* **File:** `task3_password_generator.py`
* **Description:** A tool to generate strong, secure, and random passwords containing letters, numbers, and symbols according to user-specified length.

### 3. Task 4: Rock-Paper-Scissors Game
* **File:** `task4_rock_paper_scissors.py`
* **Description:** An interactive CLI game where the user plays against the computer. It includes score tracking and allows multiple rounds.
